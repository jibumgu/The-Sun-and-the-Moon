# 해님 달님

한국 전래동화 **해와 달이 된 오누이**를 바탕으로 한 인터랙티브 연극 웹페이지입니다.
동화책 같은 그림 위에서 동아줄을 만지고, 스크롤로 해님에서 달님으로 넘어가 마지막에는 커튼콜까지 보게 됩니다.

## 미리보기

| 구간 | 장면 |
| --- | --- |
| 처음 | 위쪽에 빨간 막(커튼)이 걸린 채 동아줄을 만질 수 있음 |
| 중간 | 해가 지고 달이 떠오르며, 막이 천천히 내려옴 |
| 끝 | 막이 무대 바닥까지 내려오고, 해님·호랑이·달님이 인사하며 "커튼콜!" |

## 기능

- **패럴럭스 스크롤**: 하늘, 산, 집, 앞 잔디가 각각 다른 속도로 움직입니다.
- **낮에서 밤으로**: 스크롤에 따라 해가 지고 달이 뜨며, 하늘색과 창문 불빛이 바뀝니다.
- **동아줄 물리**: 동아줄을 잡아 당기거나 스치듯 만질 수 있습니다.
  - 정상 동아줄(금색)은 아무리 만져도 끊어지지 않습니다.
  - 썩은 동아줄(갈색)은 만질수록 마모가 쌓이다가 끊어집니다. 가만히 두면 마모가 조금씩 줄어듭니다.
  - 끊어진 동아줄은 `동아줄 복원` 버튼으로 되돌립니다.
- **커튼**: 위쪽에서 내려와 무대를 덮는 빨간 막입니다. 동화책 그림처럼 굵은 테두리와 주름을 가졌습니다.
- **커튼콜**: 스크롤 끝 구간에서 해님, 호랑이, 달님이 무대 바닥에서 올라와 인사합니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 마우스 휠 / 트랙패드 / 스크롤 | 해님에서 달님으로, 커튼콜까지 진행 |
| 화면 아래 슬라이더 | 같은 진행도를 직접 조절 |
| 동아줄 잡고 끌기 | 동아줄을 움직임 |
| 빈 곳을 드래그 | 페이지 스크롤 |
| `동아줄 복원` | 끊어진 동아줄을 모두 되돌림 |

휴대폰에서는 화면을 위아래로 끌어서 스크롤하고, 동아줄을 손가락으로 잡아 움직일 수 있습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다.

글꼴(Google Fonts)을 불러오므로 인터넷 연결이 필요합니다. 로컬 서버로 실행하고 싶다면 아래 명령을 사용하세요.

```bash
python3 -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 반응형

- **데스크톱·태블릿 (가로 화면)**: 장면 전체가 화면 가운데에 맞춰 보입니다.
- **휴대폰 (세로 화면)**: 가로폭에 맞춰 장면을 위쪽에 붙이고, 조작 패널은 화면 아래 전체 폭으로 펼쳐집니다.

## 파일 구성

```
.
├── index.html      화면 구조와 제목, 조작 패널
├── css/
│   └── style.css   배치, 글씨체, 반응형 규칙
└── js/
    └── main.js     배경 그리기, 동아줄 물리, 커튼과 커튼콜, 입력 처리
```

## 기술

- HTML5 Canvas 2D (별도 라이브러리 없음)
- Verlet 방식 물리로 동아줄 구현
- 페이지 스크롤 값을 그대로 사용해 휠·트랙패드·스크롤바와 장면이 동기화됩니다.
- 글꼴: Do Hyeon, Noto Sans KR, Gaegu (Google Fonts)
